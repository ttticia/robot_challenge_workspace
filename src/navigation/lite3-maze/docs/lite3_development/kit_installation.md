## 2 Installation Guide


### 2.1 Installation of LiDAR and Camera Modules


#### 2.1.1 Optional LiDAR + Depth Camera

① As shown in Figure a, use four M3×8 hex head screws to attach the LiDAR to the small LiDAR mounting plate. Make sure the LiDAR connector is facing the side of the mounting plate with the opening. The final assembly is shown in the figure on the right.

![cf59f157997e41408adb37f0d6b66d7b.png](images/55f068ea4139e64f7e7c.png)   ![16038e08ab534f85be521fd8b2368a29.png](images/074bbd2807b4bc596986.png)

② Use two M3×6 hex head screws with washers to attach the depth camera to the laser base plate.

[Note] With the camera's flat connector facing upward.

![911e9fbcb5d54aaba68cea1f61df5676.png](images/37b373c12f09327a7649.png)

③ Secure the small laser mounting plate to the laser base plate using two M3×8 bolts on the side closest to the camera and two M4×12 bolts on the side farthest from the camera. The installation is shown in the figure on the right.

![09e163de4ca840d2ac1e25c3bed7a7b4.png](images/df66461d8e8db268ffd0.png)   ![dc10008130c441babe794fc449313360.png](images/c7ace079c21dc4e562b2.png)

④ Secure the laser module to the robot using two M3×8 bolts on the side closest to the camera and two M3×12 bolts on the side farthest from the camera. The installation is shown in the figure on the right.

![52a6e67aed0a494e9011fd3079bbdf85.png](images/9254eb382c88677a3459.png)   ![75484db01ab24b0cb0f5c3a8f5896736.png](images/fee38c132965f992069b.png)

⑤ Install the LiDAR mounting bracket using four M5×10 bolts. The final assembly of the LiDAR and camera modules is shown in the image on the right.

![2cc6bc84828444098f5217ca45a84ac9.png](images/bb947f42e9a752a63445.png)   ![ce16d6e9738cc98edc56203fac4e9ce6.jpeg](images/0420adbe266dbfb94034.png)


#### 2.1.2 No LiDAR; depth camera available as an option only

This module is already installed on the robot dog at the time of purchase, so there is no need to install it again.


### 2.2 Installation of Computing Modules

① Secure the Orin adapter plate to the robot using one M4×10 bolt and two M3×8 bolts.

![Diagram](images/616fded81b7fbf0dd890.png)   ![609664e9f7064e23a3171fb375bd326a.png](images/f60f7358d6ada846d618.png)

② Use M2.5×55 long bolts to secure the NVIDIA AGX ORIN 64G to the AGX-orin adapter, and install the rubber protective sleeve. The result is shown in the image on the right.

[Note] Align the adapter with the AGX connector as shown in the diagram; the side of the adapter with the wider spacing between the mounting tabs should correspond to the side of the AGX module with more ports.

![d9601b557a564ebd90ce18b03b636699.png](images/61b2f12404fff1dd53af.png)   ![39374bc6f68147f5a2472bc2135cd88c.png](images/a2ec96bfe804bf2e11a1.png)

③ Use four M3×6 bolts to connect the AGX-orin adapter and the orin adapter plate, securing the module to the robot dog. To facilitate subsequent wiring, before securing the AGX module, first plug the AGX network cable (short white cable) and power cable (short black cable) into the robot dog’s rear ports, as shown in the figure on the right.

![af86a64403ed417ab2b1e0eb5288df10.png](images/b18add134ada8b968f27.png)   ![f7710968fd6041f5849e3f415c98c3aa.png](images/2198139efdeb64116dfe.png)


### 2.3 Wire Harness Connections

① Connect one end of the AGX Ethernet cable (short white cable) to the Ethernet port on the robot dog’s function box, and the other end to the Ethernet port on the AGX module; connect one end of the AGX power cable (short black cable) to the power port on the robot dog’s function box, and the other end to the power port on the AGX module.

② Insert the spoofer into the corresponding port on the AGX module.

![a200285cc21f4973872b089e5ea81805.png](images/92804ccf164590a8ac98.png)   ![f7710968fd6041f5849e3f415c98c3aa.png](images/2198139efdeb64116dfe.png)

③ Insert the Type-C end of the USB 3.0 AM-TYPE C3.1 cable (black, long cable) into the camera’s port and secure it with a bolt; insert the USB end into the USB port on the AGX module.

![da1e71d650524eaa8cece4894157af5b.png](images/e00f33c27f2727a0f840.png)   ![fd4a75ca1ad54216b6f24fe1f971ba03.png](images/045a90afa0a62d4ec705.png)

④ Connect the single end of the 1-to-3 cable to the LiDAR and tighten it securely. At the three-prong end, connect the Ethernet cable to the Ethernet port on the robot dog’s function box, connect the XT30 power cable to the 24V power port on the robot dog’s function box, and the user may configure the remaining function cable as desired.

![0e20084d23bf428bae8195b5d526ef44.png](images/e12c858174351f543208.png)   ![c1f40a0d6d684a6ba7934b74181b30bf.png](images/383883a83ed8f9147e8e.png)

The assembly of the LiDAR, camera, and computing module kit is now complete.

### 3.1 Installation and Connection Testing of Related Software


#### 3.1.1 Installing the AGX Orin Computing Module

To install and use the AGX Orin Developer Kit, please refer to the official getting-started guide:

[Getting Started with Jetson AGX Orin Developer Kit](https://developer.nvidia.com/embedded/learn/get-started-jetson-agx-orin-devkit)


#### 3.1.2 LiDAR and Depth Camera Testing

① Install RealSense Viewer and Livox Viewer on the control computer. See the links below for the installation addresses and official user guides:

librealsense（including RealSense Viewer）：[https://github.com/realsenseai/librealsense](https://github.com/realsenseai/librealsense)

Livox Viewer：[https://www.livoxtech.com/downloads](https://www.livoxtech.com/downloads)

② Unplug the Ethernet port and USB port of the 1-to-3 splitter cable from the computing module and plug them into your personal computer.

③ Launch RealSense Viewer to test whether the depth camera images are displayed correctly.

![image.png](images/10c058db85599d47ca9e.png)


④ Launch Livox Viewer and select the Ethernet IP address in the upper-left corner of the interface.

![image.png](images/c3984b6369bc3452e137.png)

When the LiDAR is functioning normally, it displays as shown in the figure below. You can move an object near the robot dog to observe whether the LiDAR image changes as expected.

![image.png](images/bc7d2e3eaee78436bceb.png)

Record the LiDAR's IP address from the command line window.

![image.png](images/ba7cb918789843cf59d0.png)

⑤ After confirming that the sensor is working properly, reconnect the Ethernet port and USB port to the AGX computing module.


### 3.2 Compiling the FAST-LIVO2 Sample Project


#### 3.2.1 Remote Connection

Use NoMachine ([https://www.nomachine.com/](https://www.nomachine.com/)) to connect to the AGX computing module.


#### 3.2.2 Downloading the Repository and Compiling Livox-SDK2

① git clone repository


```shell
git clone https://github.com/DeepRoboticsLab/fast-livo2-deep-robotics.git
cd fast-livo2-deep-robotics
```

② Compiling Livox-SDK2


```shell
cd fast-livo2-deep-robotics/src/Livox-SDK2
mkdir build && cd build
cmake .. && make -j
sudo make install
```


#### 3.2.3 install librealsense and realsense-ros

① install librealsense

Please refer to the following documentation to install Intel RealSense on the AGX computing module:

[https://github.com/realsenseai/librealsense/blob/master/doc/libuvc_installation.md](https://github.com/realsenseai/librealsense/blob/master/doc/libuvc_installation.md)

If you encounter any issues, please refer to section 2.2.1 of the following document, which lists solutions to common problems:

[https://github.com/DeepRoboticsLab/fast-livo2-deep-robotics](https://github.com/DeepRoboticsLab/fast-livo2-deep-robotics)

② install realsense-ros

Please follow the instructions in the document below to install the software:[https://github.com/realsenseai/realsense-ros](https://github.com/realsenseai/realsense-ros)

For example:


```shell
sudo apt -y install ros-humble-realsense2-*
```

If running the following command produces a reasonable visualisation, this indicates that the installation was successful:


```shell
ros2 launch realsense2_camera rs_pointcloud_launch.py
```


#### 3.2.4 Compiling FAST-LIVO2

① Install the required ROS 2 packages


```shell
sudo apt update
sudo apt -y install ros-humble-pcl-ros ros-humble-compressed-image-transport ros-humble-sophus 
```

② Compiling FAST-LIVO2


```shell
cd fast-livo2-deep-robotics/src/livox_ros_driver2/
source /opt/ros/humble/setup.bash
./build.sh humble
```

③ Verification package


```shell
cd fast-livo2-deep-robotics
source install/setup.bash
ros2 pkg list | grep livo
```

The expected output should include`fast_livo`and`livox_ros_driver2`.

④ Configuration changes

If you are using Mid-360, edit the configuration file`src/livox_ros_driver2/config/MID360_config.json`.

If you are using the Mid-360s, edit the configuration file`src/livox_ros_driver2/config/MID360s_config.json`.

Make the following changes to the relevant configuration file:

Change your IP address

In `lidar_configs`, change the `ip` to the lidar IP address recorded in section 3.1.2.

Set the host address in `host_net_info`, ensuring that the address begins with 1, as shown in the figure below.

![IP.png](images/5c63732233c81e4233ec.png)

Adjust the `width` and `height` of the image input.

![width和height.png](images/9a02e825236dc7d76f92.png)

Change the topic name.

![topic name.png](images/029b69ea9931d8105efe.png)

After the changes are made:

If you are using Mid-360, run:


```shell
ros2 launch livox_ros_driver2 rviz_MID360_launch.py
```

If you're using Mid-360s, run:


```shell
ros2 launch livox_ros_driver2 rviz_MID360s_launch.py
```

If you can see the LiDAR points in RViz, it means FAST-LIVO2 has compiled successfully.


#### 3.2.5 Running FAST-LIVO2 via ROS2 bag

① Retail_Street Dataset Download

You can download the ROS2 dataset from the original FAST-LIVO2 (Retail_Street.bag) via the following link:

[https://drive.google.com/drive/folders/15RL0__M6ZcCCf0qx8_IM40qhhoPoYnNf?usp=drive_link](https://drive.google.com/drive/folders/15RL0__M6ZcCCf0qx8_IM40qhhoPoYnNf?usp=drive_link)

[Note] The original dataset is in ROS1 format. We have converted it to ROS2 format. If you encounter any issues, please refer to Chapter 3 of the following documentation:

[https://github.com/DeepRoboticsLab/fast-livo2-deep-robotics](https://github.com/DeepRoboticsLab/fast-livo2-deep-robotics)

② Run the Algorithm


```shell
cd fast-livo2-deep-robotics
source install/setup.bash
ros2 launch fast_livo mapping_avia.launch.py use_rviz:=True
```

③ Initial Data Set

Go to the location where the dataset is downloaded and open a new terminal:


```shell
source install/setup.bash
ros2 bag play Retail_Street.db3  
# Use the spacebar to play/pause
```

This will start the mapping process and visualize it using RViz.


#### 3.2.6 Running FAST-LIVO2 on Lite3

Modify the configuration and recompile (see steps ④ and ② in Section 3.2.4), then open three terminal windows and run the following code in each one to run FAST-LIVO2 on Lite3:


```shell
# 1 
cd fast-livo2-deep-robotics
source install/setup.bash
# For the Mid-360, use msg_MID360_launch.py
# For the Mid-360s, use msg_MID360s_launch.py
ros2 launch livox_ros_driver2 msg_MID360_launch.py
```


```shell
# 2
cd fast-livo2-deep-robotics
source install/setup.bash
ros2 launch realsense2_camera rs_launch.py enable_rgbd:=false enable_sync:=false align_depth.enable:=false enable_color:=true enable_depth:=false
```


```shell
# 3
cd fast-livo2-deep-robotics
source install/setup.bash
ros2 launch fast_livo mapping_avia.launch.py use_rviz:=True
```
