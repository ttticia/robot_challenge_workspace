# Lite3 development guides

Open [index.html](index.html) in a browser for local reading, or use the Markdown copies below. These are extracted copies of the five English guides from the publicly published Lite3 development portal. Formatting differs from DingTalk. The interactive state diagram in the communication-interface guide is linked to the original; its drawing data is retained in the JSON. Original JSON is retained in `originals/`; retrieval details and node counts are in `manifest.json`. External repositories, videos, and attachments remain links. The public pages can be opened in Chrome or Edge with JavaScript enabled; a DingTalk account was not needed for this retrieval.
